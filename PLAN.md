# План: конструктор векторных композиций

Веб-сервис, который позволяет открыть исходную SVG-иллюстрацию, выделить в ней элемент,
сохранить его в библиотеку компонентов, собрать из элементов минимум трёх разных
иллюстраций новую композицию и скачать результат в SVG без потери вектора, цветов и пропорций.
Сервис ничего не генерирует — только переиспользует элементы исходников.

Правило: один этап за раз. После каждого этапа — `npm run build` без ошибок, git commit,
обновление PROGRESS.md, короткая инструкция по проверке в браузере, остановка.

## 1. Каркас
- Vite + React + TypeScript + Zustand в корне репозитория, `git init`.
- Layout из трёх зон: слева вкладки «Исходники» / «Библиотека», в центре рабочая область,
  справа слои и свойства.

## 2. Исходники
- Найти и скачать 20 SVG-иллюстраций в едином стиле со свободной лицензией (GitHub/npm),
  проверить лицензию.
- Обязательно с вложенными группами `<g>` (персонажи и предметы выделяются отдельно);
  проверить структуру, плохие файлы заменить. Положить в `raw-svg/`.
- Скрипт нормализации через SVGO: сохранять группы, инлайнить стили из `<style>` в атрибуты,
  префиксовать id по файлу → `public/sources/` + `manifest.json`.
- Атрибуция источника в README.

## 3. Просмотр исходника и выделение
- Подсветка ближайшей `<g>` при наведении, клик фиксирует выделение.
- Кнопки и стрелки «уровень выше / ниже».
- Shift+клик — несколько элементов.

## 4. Извлечение в компонент
- Учёт трансформаций родителей.
- Сбор нужных defs (градиенты, clipPath, mask — рекурсивно).
- Уникальные префиксы всех id с обновлением `url(#…)` / `href`.
- Нормализация к началу координат.
- Библиотека в IndexedDB (idb-keyval): превью, переименование, удаление.
- Тесты vitest на переименование id и сбор defs.

## 5. Холст
- Чистый SVG (никаких canvas/Konva).
- Добавление из библиотеки, перетаскивание, ручки масштаба и поворота.
- Поля X / Y / масштаб / угол, зум и пан.

## 6. Редактирование
- Дублирование (Cmd+D), удаление, отражение, порядок слоёв.
- Панель слоёв, undo/redo.

## 7. Экспорт и проекты
- Экспорт чистого SVG: каждый объект — отдельная `<g>` с id и transform, общий `<defs>` без дублей.
- Сохранение/загрузка проекта JSON, автосохранение.
- Тест: в экспорте нет дублей id, все ссылки разрешаются.

## 8. Полировка
- Подсказки, пустые состояния.
- Демо-библиотека при первом запуске.
- 3 примера композиций в `examples/`.
