# Источники иллюстраций

Все 20 исходных иллюстраций (`raw-svg/01.svg` … `raw-svg/20.svg`) взяты из набора
**Free Gophers Pack** художницы **Maria Letta**.

- Репозиторий: https://github.com/MariaLetta/free-gophers-pack
  (коммит `9bb81600dd2a9ac5a68799f9a57f02f7369c4c4e`, 22.12.2024)
- Лицензия: **CC0 1.0 Universal (public domain)**. Файл `LICENSE` в репозитории; в README сказано:
  «This package is now licensed as CC0 (public domain) so you can use the images in any way with no restrictions».
- Сам персонаж Go gopher придуман **Renée French**. Образ распространяется по лицензии
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) (см. https://go.dev/blog/gopher), поэтому автор указан здесь.

Почему выбран этот набор: единый стиль, сцены с персонажами и предметами, файлы экспортированы
из Affinity Designer с сохранёнными вложенными группами `<g>` (глубина 5–10). Проверенные альтернативы
(Flowbite Illustrations, GLPI illustrations, GitLab SVGs, Open Doodles) оказались плоскими
(экспорт из Figma/Sketch без групп) и не подошли.
